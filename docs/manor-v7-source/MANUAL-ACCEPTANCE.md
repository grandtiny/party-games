# QQ 农牧场连续人工巡检

## 1. 用途与边界

本清单用于一次启动、两个账号、不中途重置的连续人工巡检。操作顺序按当前站点和原版 V7 界面组织；发现不阻塞问题时先记录，继续后续步骤。

- 不为用例预制作物、鱼或动物的成长状态；成长流程由 owner 测试工具推进时间。
- “准备数据”只补足当前 owner 的展示库存和可识别日志，不改变土地、鱼和动物的成长进度。
- 留言、好友访问、照料和偷取必须由两个真实平台账号操作，不生成伪造好友记录。
- 测试工具只在 `MANOR_TEST_TOOLS_ENABLED=true` 时出现，且只允许平台 owner 使用。
- 本清单不覆盖已放弃的充值、元宝、论坛、QQ/Qzone 外链和外部活动。

## 2. 问题分类与等待上限

记录问题时使用以下一种结论，不只写“空白”或“卡住”。

| 分类 | 判定方法 | 记录内容 |
| --- | --- | --- |
| 明确空白 | 本清单标明允许为空，且接口成功返回空集合 | 页面、空态文案是否清楚 |
| 后端无数据 | 当前存档或接口确实没有条目，但该页不是固定空页 | 页面、请求、账号、操作前置 |
| 有数据未显示 | “准备数据”摘要或关联接口有代表项，页面仍空白/缺文字/缺图 | 代表项名称、数量、页面表现 |
| 加载不合理 | 超过下表上限，或请求结束后加载状态未关闭 | 实际耗时、是否可继续、刷新后表现 |
| 请求失败 | 页面出现超时、系统繁忙或接口错误 | 错误文案、操作、账号、是否可复现 |

本地环境等待上限：

| 操作 | 首次 | 已预热 |
| --- | ---: | ---: |
| 农场或牧场场景完整出现 | 10 秒 | 5 秒 |
| 个人信息、消息、留言、普通仓库窗口 | 3 秒 | 3 秒 |
| 商店、装饰等完整目录窗口 | 5 秒 | 5 秒 |
| 购买、出售、领取、锁定等操作反馈 | 3 秒 | 3 秒 |

首次加载包含 Ruffle 和素材初始化。超过上限后可以继续其它不受阻塞的入口，但不要为单个问题重启服务。

## 3. 一次性准备

1. 启动服务一次，记录启动时间和版本提交号；整个巡检期间不重启。
2. 在普通浏览器两个独立会话中登录账号 A（owner）和账号 B（普通账号）。
3. 两个账号都进入 QQ 农场一次，确认好友列表能互相看到。关联：SOC-01、SOC-02。
4. 账号 A 打开站点“测试”面板，点击“准备数据”一次。预期提示说明动态、农场仓库、鱼塘仓库、牧场仓库和水晶已有代表项。
5. 按需要设置账号 A 的农场/牧场等级，并发放金币；等级为精确设置，不是增加经验。
6. 不在此时推进时间。后续走到对应成长流程时再使用 `+1 小时`、`+1 天` 或 `+7 天`。

“准备数据”后账号 A 至少包含：

| 数据位置 | 可辨识代表项 |
| --- | --- |
| 农场种子 | 白萝卜种子 7 个 |
| 农场果实 | 白萝卜 13 个、牧草 25 个 |
| 农场工具 | 普通化肥 5 个 |
| 鱼塘 | 小丑鱼苗 4 个、小丑鱼成鱼 8 条 |
| 牧场背包 | 鸡 3 只、普通罐头 4 个、水拔子 3 个 |
| 牧场仓库 | 鸡蛋 6 份、兔子成体 2 只 |
| 材料/水晶 | 蓝水晶 5 个 |
| 动态/系统 | 7 条以 `[巡检样本]` 开头的记录，其中 2 条可归入消费记录 |

重复点击只补足最低数量，不重复添加同名日志。用户后续消耗的物品会在再次点击后补足。

## 4. 农场连续巡检

### 4.1 首屏和左上角入口

1. 检查账号名、头像、等级、经验、金币、VIP 标识、土地、房屋、工具栏和好友栏是否完整且不重叠。关联：PLAT-08、ECO-01、ECO-04。
2. 点击头像/个人信息，检查本地头像、昵称、等级、金币和形象文字；头像不得为空，窗口 3 秒内完成加载。
3. 点击“消息”，从左到右依次打开六个页签：消息、留言、成果、成鱼、消费、系统。关联：SOC-10 至 SOC-12、ECO-15。
4. “消息”应显示 `[巡检样本]` 动态，不得出现 `null` 或 `00:00` 的伪记录；“成果”应至少显示白萝卜和牧草的真实数量与图片；“成鱼”应显示 8 条小丑鱼及图片；“消费”应至少显示购买白萝卜种子和普通罐头；“系统”应显示巡检样本。
5. “留言”在账号 B 留言前允许为空，分类为“后端无数据”，不是页面缺陷。分别从 A、B 的好友入口打开对方留言板，内容必须属于被查看账号；用 B 给 A 留下唯一文本，留言只能写入 A 的面板。回到 A 后 3 秒内应看到发送者、内容和时间，A 回复后 B 再查看回复。关联：SOC-10。
6. 点击“公告”，应显示本站本地公告，不应跳腾讯页面。关联：FARM-27。
7. 点击“礼包”。未领取时应能领取；当天已领取时必须明确提示已领取，农牧场共享当天状态。关联：EVT-01、ECO-05。
8. 点击签到和升级礼包入口。签到显示当日次数和连续天数；升级礼包不得重复领取同一级。关联：EVT-02、EVT-03、EVT-06。

### 4.2 工具栏、仓库和商店

1. 依次切换拖动、收获、翻地、放虫、物品包、工具箱、升级土地、放草、野生动物、捞鱼等可见工具；选中态、鼠标提示和场景操作必须一致。关联：FARM-01 至 FARM-15、WILD-01 至 WILD-09。
2. 打开物品包：种子应看到白萝卜，工具应看到普通化肥，鱼苗应看到小丑鱼苗；有数量但文字或图标缺失记为“有数据未显示”。
3. 打开农场仓库：果实应看到白萝卜和牧草。分别测试单个出售、全部出售、锁定和解锁；锁定物品不得被全部出售。关联：FARM-16 至 FARM-20、ECO-11。
4. 打开鱼塘仓库/成鱼列表：应看到小丑鱼。测试锁定、解锁和单项出售。关联：FISH-01 至 FISH-09。
5. 打开种子、工具、装饰商店，逐个切页并滚动到末尾；目录 5 秒内出现，名称、等级、金币价格、图片和购买反馈一致。关联：CAT-02、CAT-04、CAT-06、ECO-09、ECO-10。
6. 打开装饰/农场形象/告示牌，至少默认项有名称和预览；购买后可选择、保存并在刷新后保留。关联：FARM-21、FARM-22。
7. 打开扩建和土地升级。设置到规则要求等级后检查费用、目标土地和反馈；达到 28 级只发放一次土地升级基金，基金在达到等级时发放，不以普通扩建触发。关联：FARM-09、FARM-10、FARM-30。

### 4.3 土地、鱼塘和好友

1. 用现有土地完成浇水、除草、除虫、施肥、收获、翻地；操作反馈 3 秒内出现，状态不应长时间滞后。关联：FARM-01 至 FARM-08。
2. 在需要成熟时用测试工具推进时间，不刷新、不重启；确认客户端状态随后刷新。
3. 鱼塘未开通时应显示可开通流程；开通后完成放鱼苗、成长、施肥、收获和出售。关联：FISH-01 至 FISH-09。
4. A、B 互访农场。检查主人名称和好友鱼塘均来自目标账号，不得显示访问者自己的鱼塘。关联：SOC-03。
5. 用 B 对 A 完成照料、偷菜、偷鱼和允许的恶作剧；回到 A 的动态确认操作者昵称和结果。关联：SOC-04、SOC-05、SOC-07、SOC-08、SOC-11。

## 5. 牧场连续巡检

### 5.1 场景和左上角入口

1. 从农场场景内入口切到牧场，再从站点场景标签切回农场和牧场；两条入口都应生效，预热后 5 秒内完成。关联：PLAT-14、SOC-03。
2. 检查账号名、等级、金币、饲料机、窝棚、棚、动物、工具栏和好友栏是否完整且不重叠。
3. 依次点击左上角“消息”“留言”“公告”“礼包”。消息默认打开个人信息的消息页；留言必须直接打开留言页，不得两者都停在同一页。关联：SOC-10 至 SOC-12。
4. 公告当前允许返回空列表；入口不得超时或卡死。记录为“明确空白”，关联：PAST-30。
5. 礼包与农场共享当天领取状态：农场已经领取后，牧场入口应隐藏或明确提示今天已领，不得无反馈。关联：EVT-01。
6. 个人信息页签与农场相同；牧场“成果”应看到鸡蛋和兔子成体，消费和系统应有巡检样本。

### 5.2 背包、仓库和商店

1. 打开牧场背包：动物应看到鸡，常规道具应看到普通罐头，武器应看到水拔子；牧草数量显示整数。关联：PAST-04、PAST-07、PAST-11。
2. 打开牧场仓库：副产品看到鸡蛋，成体看到兔子；测试单项出售和全部出售。关联：PAST-12、ECO-11。
3. 打开材料/水晶页：至少看到蓝水晶；无活动卡片属于当前目录边界，不要求伪造缺素材的 2001–2008 卡片。关联：WILD-07、CAT-11。
4. 依次打开动物、餐厅专供、VIP 动物、牧草、常规道具、武器、装饰和看守商店。已接入目录 5 秒内出现；被目录明确隐藏的活动项不算空白缺陷。关联：CAT-03、CAT-04、CAT-06、PAST-07、PAST-21。
5. 检查标价和实际扣款一致；全员 VIP 仅影响标识和限次礼包，无限免费商品已按本地金币价结算。关联：ECO-04 至 ECO-10。
6. 装饰购买后应进入库存、可以启用并持久化；不得打开充值或腾讯会员链接。关联：PAST-20、ECO-02、ECO-03。

### 5.3 动物生命周期、好友和野生动物

1. 按“幼崽成长 -> 成熟 -> 手动拖入生产 -> 生产完成 -> 收取副产品 -> 生产次数耗尽 -> 收获成体”的顺序测试。每个阶段只在需要时推进时间。关联：PAST-01 至 PAST-06。
2. 确认成熟后不会直接跳到收获期，拖动提示出现后可拖入正确区域，第二次点击不应无故改变阶段。
3. 测试饲料机：从背包添加牧草、金币购买牧草、动物消耗；每次成功时金币/背包/饲料机只能有一套一致变化。关联：PAST-07、PAST-08。
4. 测试便便、蚊子、老鼠、看守、窝棚/棚升级和科研；没有目标时应明确提示，不得显示请求超时。关联：PAST-13 至 PAST-24。
5. A、B 互访牧场并完成开始生产、特殊喂养、偷副产品、放蚊子、清理和抓鼠；双方状态原子更新，动态昵称正确。关联：SOC-03、SOC-04、SOC-06、SOC-08、SOC-11。
6. 测试野生动物开槽、领养、放生、攻击、回归、捐赠、水晶拾取和出售；攻击记录必须显示真实账号昵称。关联：WILD-01 至 WILD-09。

## 6. 连续性和收尾

1. 不退出账号，往返农场、牧场和好友场景，确认金币、等级、库存、礼包状态、留言和动态保持一致。
2. 同一页面进行多次购买、出售、领取和留言，确认第一次之后仍有反馈，不能只在首次操作生效。
3. 只刷新页面一次，确认两账号恢复各自存档，没有串号、好友鱼塘串用或库存回退。
4. 记录所有问题的账号、场景、入口、前置步骤、问题分类、实际等待时间和是否阻塞后续；不在巡检途中重置数据。
